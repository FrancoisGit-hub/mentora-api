## 2. Fixes

**Finding #2**: `Mentora.Infrastructure/Services/CoachMeService.cs`. Both sold counts add
`v.OrderItem.Order.Origin == PurchaseOrigin.MemberPurchase`. EF turns this into two INNER JOINs within the
same single `count(*)` query, so there is still one query per figure and no N+1. No DTO changes. The existing
conditions (coach, created-date window) are kept. There was no paid-status condition on these two counts
before: vouchers are only ever created for paid orders.

**Finding #3**: `Mentora.Infrastructure/Services/ExerciseService.cs` (`ListForCoachAsync`). The pattern
is now `"%" + EscapeLike(search.Trim()) + "%"`, passed to `EF.Functions.ILike(..., "\\")`, the same helper
and ESCAPE character as `ListForMemberAsync`. Nothing else in the method changed.

**Build**: `dotnet build --no-incremental` → **0 errors, 19 warnings** (unchanged).
